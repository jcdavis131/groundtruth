# Licences, one row per publisher

What each publisher behind a committed snapshot collection says it grants, read from the publisher's own page, and what groundtruth grants on top of that. The code is MIT, in [LICENSE](../LICENSE). This file is about the data. A row is here for each publisher that a collection under [`data/manifests/`](manifests/) takes a source or a join from, and for the one other publisher the Hugging Face dataset ships: the SEC, for the companies file. The map and the MCP server relay many more sources, and each carries its own licence note in `apps/map/lib/provenance/sources.ts`; this table does not cover them.

Our stance is clean-room: nothing here waits on a terms review, we grant nothing beyond what a publisher's own page grants, we keep the credit lines publishers ask for, and where a publisher's terms leave a gap we say so and claim nothing for it.

Compilation licence: not yet chosen (Cam decides; until then the bundle carries no licence of its own and each record stays under its publisher's terms)

## Reading the table

- **Collections** are the folders under `data/manifests/` whose manifests name this publisher's source (`sources[].sourceId`). The test ties each source id to its publisher in `SOURCE_PUBLISHERS` (`data/schema/licenses.test.mjs`), so a collection is covered only by the row of the publisher of its own source. A publisher that is the source of no collection says `none`. **Also used for** says what else the publisher's data is used for: a boundary file a manifest joins (`joins[].boundary.publisher`, which is how the Census Bureau is here), or a file on the Hugging Face dataset that is not a manifest collection (the SEC, and the Census ZCTA files). A collection named there does not make the row its source.
- **What they grant** is one of three things, per terms URL: a quote of under 25 words from that page (straight quotes, typographic quotes and dashes written plain, the words exactly as the page has them); `terms page states no licence` (the page's text has no licence, public-domain, copyright, terms-of-use or permission word); or `no terms page found`, with what was looked at. A licence name that no page gave is never written here: a name such as CC0, CC BY, Creative Commons, MIT, Apache, ODbL, GPL, BSD, MPL, PDDL, Unlicense or "public domain" may stand in a statement only inside the quote the lock found on the page, and the test rejects one anywhere else in the cell.
- **What we grant on top** is always `nothing beyond their terms`. A record in a snapshot keeps its publisher's terms. We add no licence to it, and the bundle's own licence is the open line above.
- **Public domain, where a page says it, is the page's word.** Federal works are outside copyright by 17 U.S.C. 105, but a compilation of records that others submitted is not necessarily one: `apps/map/lib/provenance/licenceTerms.ts` reads the National Inventory of Dams that way and claims no grant for it, and so does this table. The committed `nid-dams` manifests say `"licence": "public domain"` in `sources[]`; they were written before this table, no USACE page read for it says so, and a committed manifest is never edited in place. The Hugging Face card's line about "US federal public-domain sources" is Cam's wording and is not changed here.
- **Retrieved** is the UTC day the page was fetched. [`licenses.lock.json`](licenses.lock.json) holds, for each terms URL, the status, byte count and sha256 of what came back, the User-Agent sent, and whether the quote was on the page. The quote is the durable check: census.gov and nps.gov pages change without their terms changing, so a sha256 can differ on a later fetch while the quote still holds.

## Adding or re-reading a row

[`data/PIPELINE.md`](PIPELINE.md) (Licences) has the commands. In short:

1. Read the publisher's own terms page. A statute, a catalogue entry (data.gov, an aggregator) or memory is not the publisher's page.
2. Add the page to `TARGETS` in [`data/pipeline/licenses_fetch.py`](pipeline/licenses_fetch.py) with the sentence to quote, or with the licence words to search for if you mean to write `terms page states no licence`. `python -I data/pipeline/licenses_fetch.py --write` fetches every target at one request a second per host, refuses to write the lock if a quote is not on its page, and rewrites the lock.
3. Add the row. Cells hold no `|`; several URLs in a row go in the cell separated by `<br>`, with one statement per URL in the same order. The Collections cell backticks the folder names under `data/manifests/` whose manifests name this publisher's source, and a new source id also needs a line in `SOURCE_PUBLISHERS` in the test; a publisher that is the source of no collection says `none`, and the join or file it is used for goes under Also used for.
4. `node data/schema/licenses.test.mjs` fails a collection whose source's publisher has no row naming it, a row that names a collection it publishes no source of, a join publisher a manifest names with no row naming that collection under Also used for, a terms URL that is not https, a quote of 25 words or more or not the one the lock found, a licence name outside that quote, a grant on top, a statement that the service's copyrightText is empty that the lock does not back, a publisher of a file the Hugging Face dataset ships beyond the manifests (`EXTRA_FILES` in `data/hf/publish.py`: the SEC and the Census Bureau for the companies file) with no row naming that file under Also used for, and a table that has lost the compilation line.
